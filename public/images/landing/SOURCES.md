# Hero image sources

The seven default hero images are local JPEG downloads from Unsplash. They are
used when a hero slot has no campus-specific upload. The app serves local
copies and does not request these images from Unsplash at runtime. Unsplash's
license permits free commercial and non-commercial use:
https://unsplash.com/license
